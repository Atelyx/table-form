# 表格表单

把多维表格的行变成可填写表单的**表格视图**插件（`tableview` 类型）。启用后，打开任意 `.atb` 表格，工具条「视图」下拉会出现「表格表单」选项。

> **宿主要求：Atelyx 0.4.3 及以上**（插件包格式：`package.json` + 入口默认导出 `apply(ctx)`）。

## 功能

- **按类型渲染字段**：文本 → 多行输入；数字 → 数字输入；时长 → 秒数输入；单选 → 选项按钮或下拉（按字段配置）；图片 → 平铺正方形展示，选中已有行时可移除单张图片引用。
- **与表格一致的编辑手感（无保存/提交按钮）**：字段显示为只读输入框，**双击进入编辑**（accent 高亮边框 + 轻晕圈），**失去焦点（或文本框 Ctrl/⌘+Enter）即写入表格**，Esc 放弃本次编辑（与宿主表格单元格一致）；单选类没有只读态，点选项或改下拉即写、「清空」显式置空。全程逐格写，不批量覆盖。编辑中的输入框不会被协作者的并发写入覆盖。
- **字段顺序默认 = 表格字段顺序**（含图片字段排在其列位），可在表单设置里用上下按钮调整。
- **顶栏行导航**：行选择器（支持按行内容搜索，列出前 50 条匹配）+ 上一行/下一行按钮；表单主体左右两侧另有整块可点的翻行热区（悬停高亮显示 `‹` / `›`，首尾循环、铺满可视高度且不随内容滚动）；「新增一行」按钮常驻顶栏。行号与「共 M 行」显示在表单头部。
- **默认载入第一行**：进入某个表格的表单视图时自动载入第一行；没有行数据时显示空表引导。每个表格只自动载入一次，之后由用户通过行选择器或翻行切换（用户主动新增后不会被抢回）。
- **新增行**：在新增态下填写第一个值时会自动在表格末尾新增一行（状态显示「已第 N 行新增，继续填写」），之后同样逐格失焦写入；5 秒内可一键撤销本次新增（仅当该行内容未被改动过）。也可点「新增一行」显式建空行。
- **实时协作**：与表格视图共用同一份表格数据与协作通道——任一端的写入都会即时反映到另一端的表格与表单视图；编辑某行时，同看该表格的其他在线用户会以各自颜色在该行上提示。正在编辑的行被协作者删除时回到新增态并提示。
- **表单设置**：在**表格工具条右上角**的「表单设置」按钮打开浮层（与表格网格视图、表单视图共用同一个工具条；点外部或 Esc 关闭），可配置字段启用/停用（按列序默认全开）、填写提示、上下排序、单选渲染样式。配置随改动即时保存，**按表格文件分别记忆**。

## 图片字段

图片单元格的图片文件由宿主导入到表格附件目录，插件没有写入图片字节的通道，因此**不能添加图片**；选中已有行后，把鼠标悬停在图片上会出现移除按钮，点击即从单元格移除该图片引用（附件文件的回收由宿主在切表/关闭时处理）。

展示方式为**平铺正方形**：每张图 1:1（`object-cover` 裁切），多图时每行两端顶格、彼此只留 4px 间隙、行满换行；方块边长有上限，框很宽时也不会把单张图撑成巨块；图片多于框高时在框内纵向滚动。**点击任意一张进入放大预览**（全屏遮罩、居中大图、左右键/按钮循环切换、`n / 总数` 计数、Esc 或点遮罩关闭）。无图时提示「该行此字段暂无图片」，未选中行时提示「选中一行后显示该行的图片」；读取失败的条目显示占位块、给出通知并在控制台记录原因，不阻塞其余图片浏览。

## 安装与启用

1. 设置 → 插件 → 「从本地文件夹安装」选择本插件源码目录（或放入 `app_data_dir/plugins/com.atelyx.table-form/`）。
2. 启用「表格表单」。
3. 打开一个 `.atb` 表格，工具条「视图」下拉选择「表格表单」。

## 权限说明

- `table`：读取当前表格的行/字段/选中行与图片；新增行并按字段写入单元格值；移除图片单元格的图片引用。
- `state`：读写本插件的表单配置（按表格文件分别保存）。
- `notification`：提交或保存失败、并发冲突、图片读取失败时提示。

## 数据通道

本插件使用插件平台的 `ctx` API：

- `ctx.table.snapshot()` + `table:changed` 事件 — 当前表格数据快照（行/字段/选中行/协作选中行用户色）。
- `ctx.table.addRow()` / `ctx.table.updateCell(rowId, fieldId, value)` — 新增行、写入或更新单元格值（含写回移除图片后的 images 数组）。
- `ctx.table.removeRow(rowId)` / `ctx.table.selectRow(rowId)` — 撤销本次新增、定位到指定行。
- `ctx.table.resolveImage(entry)` — 图片条目 → dataURL（图片展示与放大预览，结果在插件内缓存共享）。
- `ctx.state.read(pluginId)` / `ctx.state.write(pluginId, data)` — 本插件的表单配置。
- `ctx.slots.registerTableView(...)` — 注册表格编辑器内视图。

> 新增行的稳定 id 由宿主生成且不作为返回值暴露，插件侧以「新增前后的行 id 集合差集」定位新行；当同一时刻恰好有其它窗口也在新增行时差集不唯一，插件会中止本次提交并提示重试，不会把值写到错误的行上。

## 开发说明

本插件无构建步骤、无运行依赖：`index.ts` 即源码即产物（宿主加载时转译）。改了源码后，本地目录来源的插件即时生效。

本地静态校验：TypeScript 严格模式（`tsc --noEmit -p tsconfig.json`）+ ESLint（react-hooks 规则，配置见 `eslint.local.mjs`）。`types/cordis.d.ts` 是让插件仓库能独立跑 `tsc` 的类型桩；`tsconfig.json` / `eslint.local.mjs` 只服务本地校验，不参与插件运行时。
