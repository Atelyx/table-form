# 表格表单

把多维表格（`.atb`）的一行渲染成一屏表单：按字段类型出控件，编辑逐格写回，与表格视图共用同一份数据。

> **宿主要求**：Atelyx 新插件平台（进程型插件，`apiVersion = 1`），且已开放插件表格服务域（表格读写 + 表格视图挂载）。

## 功能

- **按类型出控件**：文本 → 单行输入；时长 → 单行输入（`1:30:00` / `30:00` / 秒数，落盘为秒）；数字 → 数字输入（带步进钮）；单选 → 下拉或选项按钮；图片 → 缩略图条（灯箱看大图、逐张移除、添加图片）；其余类型只读展示。
- **逐格写回**：输入停顿后合并写入，翻行、新增行、刷新、进出设置、关闭视图时立即落地；写失败保留原值并提示原因，不把失败显示成成功。
- **行导航**：上一行 / 下一行、新增行（直接定位到新行）、删除当前行、刷新，头部显示「第 N / M 行」；翻行会把选中态同步给表格，切回网格视图看到同一行。打开表单时落在表格里正选中的那一行。
- **表单设置**：顶部「完成」返回填写，可逐字段显示 / 隐藏、排序、填写提示、切换单选的按钮 / 下拉样式；改动即时保存。
- **按表格记忆**：配置按表格文件分别保存，损坏时退回默认并留痕。
- **跟随表格**：表格打开、切换、数据变更会自动重读，并尽量停在原来那一行。

## 图片字段

一条横向缩略图（末尾一枚「添加图片」钮，空格子直接给添加钮）：点「添加图片」从本机选一张图，导入表格附件目录（删表时随表格清理）后追加进该格；点缩略图进灯箱预览——浮层盖住表单，图片等比放大居中，左右按钮或方向键（点图片取得键盘焦点后）翻张，点图片外任意处或 Esc 退出；悬停缩略图右上角浮现移除钮。

图片引用按仓库相对路径、http(s) 外链与本机绝对路径直接显示成图；越界相对路径等读不到的引用保留纯文本。

## 安装与启用

1. `cargo build --release` 产出可执行入口（Windows 为 `table-form.exe`）。
2. 新建 `dist/`，只放入 `plugin.json` 与该可执行文件。
3. 在设置 → 插件「从本地文件夹安装」选择 `dist/`，装完在列表里启用「表格表单」。
4. 打开一个 `.atb` 表格，在工具条「视图」下拉选择「表格表单」。

安装是整目录复制，改码后需重新复制 `dist/` 并重装。

## 权限

- `table`：读取表格快照、写入单元格、新增 / 删除行、同步选中态。
- `vault`：把选中的图片导入表格附件目录。
- `dialog`：弹出系统文件选择框。
- `state`：读写表单配置。
- `notification`：失败与阻断提示。

界面挂载与提交属宿主时序方法，不占权限。

## 开发

`cargo build --release --offline` 产出可执行入口（`target/release/`）；`cargo test --offline` 跑界面树、事件解码、写回时序与配置用例；`cargo clippy --offline --all-targets` 做 lint。插件依赖同机 Atelyx 仓库的 `atelyx-plugin-sdk`（`Cargo.toml` 以相对路径引用）。
